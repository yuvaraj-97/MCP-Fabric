# Project Directions

- Read `docs/multi-agent-execution-plan.md` before delegating work across
  Codex, Claude, and Antigravity.
- Use `claude -p "<prompt>"` for non-interactive Claude CLI prompts.
- Use `agy -p "<prompt>"` for non-interactive Antigravity CLI prompts.
- Run `agy -p` outside restricted sandboxes when needed; it writes logs under `~/.gemini/antigravity-cli` and opens a localhost language-server socket.
- Keep prompts and captured outputs concise when using these CLIs for verification.
